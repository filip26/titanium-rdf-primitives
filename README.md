## Installation

```xml
<dependency>
    <groupId>com.apicatalog</groupId>
    <artifactId>titanium-rdf-primitives</artifactId>
    <version>${rdf.primitives.version}</version>
</dependency>
```

## Contributing

All PR's welcome!


### Building

Fork and clone the project repository.

```bash
> cd titanium-rdf-primitives
> mvn package
```
